## Implementation

- Same-account confirmed lesson and correction origins now earn bounded deeper reads independently of vocabulary. Up to four origins/lexical candidates; up to twenty origin lookups beyond the latest fifty missions. This is candidate retrieval, not a structural-match claim.
- Sources carry server-attached project provenance. Explicit public repository links retain the project that supplied them. An optional structural bridge requires different project origins, exact supplied excerpts, a shared relationship, a short rationale, an application and a proof requirement. Lesson-backed bridges additionally require a supplied account-scoped lesson from the prior project. A bridge alone remains a model hypothesis.
- The existing first call becomes a structured baseline only when confirmed lesson sources are actually supplied. That baseline withholds lesson records. The existing second call critiques it with the complete packet. No extra provider call, provider dependency, UI, voice or navigation change.
- Each new review persists baseline/final decision fields, changed field names, withheld source IDs, applied lesson ID, explicit `human_intervention_required` and its basis. Source cache version 8 invalidates earlier packets. Restoration revalidates proposals and recomputes the classification.
- Intervention detection queries the full count of target context/step/finish-line/correction events since the earliest supplied lesson confirmation, independently of prompt clipping. Target objective updates and a current supplied answer or requested clarification also count. Missing measurement information fails closed. False means no intervention observed in this explicitly bounded temporal scope; it does not prove autonomous capability.
- A changed comparison is only `changed_candidate`. **Inheritance remains Unknown in every automatically generated observation.** Critique order, sampling, retained underlying artifacts, and the lack of independent outcome verification prevent a causal success claim. Raw text changes are not scored as successful transfer.

The existing transitional review ledger remains the persistence owner. No schema, credentials, grants, model access, external tools or confirmation authority changed.
